cd backend

Step 1 — Install Rust & Cargo

Go to the official Rust website:

Rust Installer

Download and run:

rustup-init.exe

During installation:

Choose default installation (1)
Wait until installation completes

Cargo will automatically install with Rust.

Step 2 — Restart Terminal

After installation:

Close Git Bash completely
Open Git Bash again

Then verify installation:

rustc --version
cargo --version

cargo init
